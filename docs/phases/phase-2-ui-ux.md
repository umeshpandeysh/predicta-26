# Phase 2: UI/UX Console Prototype

This document registers the design system and interactive elements implemented in the Predicta single-page dashboard.

## 1. Design Aesthetics
*   **Color Palette:** Dark Deep Space Indigo (`#0B0F19`) background, Neon Cyan (`#00F2FE`) interactive accents, and Warning Amber/Red (`#FF5E62`) alert states.
*   **Typography:** Google Font Outfit & Inter for high-density, technical data readability.

## 2. Interactive Screens
*   **Overview Dashboard:** High-level metrics, burn-in timeline progress, lot distribution curves, and a system info hero widget.
*   **Lot Analysis:** Filters and sorts components by anomalies or wear-out states within specified lots.
*   **Component Detail:** Tracks specific parts, showing 0h and 24h readings, Module A explainability, and Module B forecasting trend lines with confidence intervals.
*   **Model Registry:** Lists training iterations, calibration lot sizes, and active model tags.
