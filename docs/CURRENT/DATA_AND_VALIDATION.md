# PREDICTA-26 ? Data Generation & Scientific Validation Methodology

---

## 1. Synthetic Data Generation Architecture
Predicta-26 uses a physics-grounded semiconductor data generator (`src/physics/unified_generator.py` and `ml/data_generator/generate_dataset.py`) to simulate realistic manufacturing variance across 20 distinct wafer lots (50,000 total dies).

### Modeled Physical Mechanisms
1. **Lot-Level Physical Variations:**
   - Threshold voltage shift: Delta V_th ~ N(0, 0.025 V)
   - Oxide thickness variation: T_ox ~ N(0, 0.03 nm)
   - Interconnect sheet resistance: R_sheet ~ N(0, 0.05 Ohm)
2. **Wafer Radial Gradients:**
   - Radial die coordinate normalized from center to edge (r_norm in [0.0, 1.0]).
   - Edge-die leakage multiplier: I_leak(r) = I_leak0 * (1 + 1.8 * r_norm^2).
3. **Equipment Chuck Biases:**
   - Systematic contact resistance (0.05 to 0.25 Ohm) and thermal chuck offsets across tools `EQP-101` through `EQP-105`.
4. **Physical Failure Envelope Boundaries:**
   - Labels emerge strictly when dies violate physical boundaries (timing slack < 0, thermal runaway T > 125 C, dielectric breakdown E_ox > 8 MV/cm), with zero hardcoded label shortcuts.

---

## 2. Anti-Leakage Partitioning
To guarantee scientific validity, the 50,000 dies are partitioned via hierarchical `GroupShuffleSplit` on `lot_id` and `wafer_id`:
- **Training Set (65.0%):** 32,500 records across Lots 001 to 013.
- **Validation Set (20.0%):** 10,000 records across Lots 014 to 017.
- **Locked Test Set (15.0%):** 7,500 records across Lots 018 to 020.

Train Lots, Validation Lots, and Test Lots are strictly mutually disjoint:
Train Lots intersect Validation Lots = Empty
Train Lots intersect Test Lots = Empty
Validation Lots intersect Test Lots = Empty

All preprocessors, reference MAD distributions, and Platt calibration parameters are fitted exclusively on the Training and Validation partitions. The locked test set remained untouched until final evaluation.

---

## 3. Real-World Validation Limitation & Fab Integration Roadmap

> [!CAUTION]
> **Real-World Validation Limitation:**
> The current system has been validated on physics-grounded synthetic semiconductor telemetry and public proxy datasets (NASA MOSFET aging, STMicroelectronics AWFD, UCI SECOM). It has not yet undergone live fab integration on proprietary commercial silicon lines.

### Integration Roadmap for Proprietary Fab Data
1. **STDF / ATDF Ingestion:** Native parsers for Standard Test Data Format v4 records generated by Teradyne / Advantest ATE systems.
2. **Domain Adaptation:** Fine-tune the 350-tree XGBoost weights on 5,000 real fab probe records to adjust for fab-specific parasitic capacitances.
3. **Statistical Baseline Recalibration:** Recalibrate PAT and COPOD baseline medians on 1,000 known good dies from the initial qualification lot.
